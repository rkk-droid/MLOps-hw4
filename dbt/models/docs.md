{% docs fraud_rate %}
Доля мошеннических транзакций в процентах: 100 * число фродов / число транзакций. Допустимый диапазон от 0 до 100.
{% enddocs %}

{% docs amount_bucket %}
Сегмент суммы. small — меньше 10, medium — меньше 50, large — меньше 200, xlarge — 200 и больше. Порог 200 близок к глобальному 95-му перцентилю суммы.
{% enddocs %}

{% docs is_large_transaction %}
1, если сумма не меньше 200 (сегмент xlarge). Доля таких транзакций — «доля крупных» в дневной витрине.
{% enddocs %}

{% docs risk_segment %}
Сегмент риска клиента по его fraud_rate. HIGH — не ниже 2%, MEDIUM — от 0.5% до 2%, LOW — ниже 0.5%. Пороги лежат в переменных проекта.
{% enddocs %}

{% docs is_suspicious %}
1, если fraud_rate мерчанта не ниже 1.5% и у него не меньше 100 транзакций.
{% enddocs %}

{% docs is_elevated_risk %}
1, если fraud_rate этого дня недели и часа не ниже 1.5 долей общей fraud_rate.
{% enddocs %}
